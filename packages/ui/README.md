# RepWise UI package

This package contains shared semantic design tokens and accessible interface
primitives for RepWise applications. Product code should consume the tokens in
`src/tokens.css` instead of redefining brand, status, focus, or contrast colors.

The [interface specification](../../RepWise_UI_UX_README.md) defines normative
responsive, interaction, content, and accessibility behavior. A component change
must preserve keyboard access, visible focus, reduced-motion behavior, and all
documented loading, empty, error, disabled, and success states.
